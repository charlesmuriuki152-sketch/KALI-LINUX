

## 1. Objective
To learn how to create, edit, save, and verify a text file using the Nano text editor in Linux.

## 2. Tools Used
- Kali Linux (WSL)
- Nano text editor
- Linux terminal
- `cat` command
- `ls` command

## 3. Procedure

### Step 1: Create a File Using Nano

Executed the following command to open Nano and create a new file in `/tmp`:

```bash
nano /tmp/mynotes.txt
```

**Screenshot:** Insert screenshot of Nano opened with the new file.

### Step 2: Enter Text

Entered the following text into the Nano editor:

```text
My Linux Learning Journey

I am learning Linux commands.
I am practising file management.
I am building my cybersecurity skills.
```

**Screenshot:** Insert screenshot showing the text inside Nano.

### Step 3: Save and Exit

Saved the file using the following keyboard shortcuts:

- `Ctrl + O` – Save the file (Write Out).
- `Enter` – Confirm the filename.
- `Ctrl + X` – Exit Nano.

**Screenshot:** Insert screenshot showing the saved file or terminal after exiting Nano.

### Step 4: Verify the File Using Cat

Executed:

```bash
cat /tmp/mynotes.txt
```

The command displayed the text saved in the file, confirming that the contents were successfully written.

**Screenshot:** Insert screenshot showing the output of the `cat` command.

### Step 5: Confirm File Existence

Executed:

```bash
ls -l /tmp/mynotes.txt
```

This displayed the file's details, including permissions, ownership, file size, and modification date.

**Screenshot:** Insert screenshot showing the `ls -l` output.

## 4. Commands Learned

| Command | Description |
|---|---|
| `nano /tmp/mynotes.txt` | Creates or opens a file in Nano. |
| `Ctrl + O` | Saves the file. |
| `Ctrl + X` | Exits Nano. |
| `cat /tmp/mynotes.txt` | Displays file contents. |
| `ls -l /tmp/mynotes.txt` | Displays file details. |

## 5. Challenges Encountered

No major challenges were encountered during the exercise. The main learning point was understanding Nano's keyboard shortcuts for saving and exiting the editor.

## 6. Results

- Successfully created `mynotes.txt` in `/tmp`.
- Entered and saved text using Nano.
- Exited the editor successfully.
- Used `cat` to verify the saved contents.
- Used `ls -l` to confirm the file's existence and inspect its details.

The lab provided practical experience with the Nano text editor and Linux file management. I learned how to create, edit, save, and verify text files directly from the terminal.
