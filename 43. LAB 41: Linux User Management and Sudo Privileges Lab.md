

## 1. Objective

The objective of this lab was to:

1. Create a new Linux user using `useradd`.
2. Assign the new user an initial password using `passwd`.
3. Grant the new user sudo privileges.
4. Switch to the new user.
5. Verify that the new user can execute commands requiring root privileges.

## 2. Environment

- Operating System: Kali Linux
- Environment: Kali Linux on WSL2
- Original user: `charles`
- New user: `CAT`
- Shell: Bash

## 3. Creating a New User

Created a new user named `CAT` using:

```bash
sudo useradd CAT
```

This command created the CAT user account.

## 4. Setting the User Password

Assigned an initial password to CAT:

```bash
sudo passwd CAT
```

The system requested a new password and confirmation.

Successful output:

```text
New password:
Retype new password:
passwd: password updated successfully
```

## 5. Switching to the New User

Switched from the original account to CAT:

```bash
su - CAT
```

Verified the active user:

```bash
whoami
```

Output:

```text
CAT
```

## 6. Granting Sudo Privileges

Initially, CAT could not execute sudo commands because the account did not have sudo privileges.

The following error appeared:

```text
CAT is not in the sudoers file.
This incident has been reported to the administrator.
```

Returned to the original user:

```bash
exit
```

Added CAT to the sudo group:

```bash
sudo usermod -aG sudo CAT
```

Verified group membership:

```bash
groups CAT
```

The output should include the `sudo` group.

## 7. Creating the User's Home Directory

During login, the following warning appeared:

```text
su: warning: cannot change directory to /home/CAT:
No such file or directory
```

This happened because the CAT account did not have a home directory.

Created the directory:

```bash
sudo mkdir -p /home/CAT
```

Assigned ownership to CAT:

```bash
sudo chown CAT:CAT /home/CAT
```

## 8. Testing Sudo Privileges

After granting sudo privileges, logged in again:

```bash
su - CAT
```

Tested sudo access using:

```bash
sudo whoami
```

Expected output:

```text
root
```

This confirms that CAT can execute commands with root privileges.

Another command from the exercise is:

```bash
sudo ls /root
```

This tests whether CAT can list the contents of the root user's home directory.

## 9. Challenges Encountered and Solutions

### Challenge 1: Password not set initially

**Problem:** CAT could not authenticate using sudo because the account password had not been configured.

**Solution:**

```bash
sudo passwd CAT
```

### Challenge 2: Missing home directory

**Problem:** Logging in produced a warning that `/home/CAT` did not exist.

**Solution:**

```bash
sudo mkdir -p /home/CAT
sudo chown CAT:CAT /home/CAT
```

### Challenge 3: User not in the sudoers file

**Problem:** CAT received a sudoers error when attempting to execute privileged commands.

**Solution:**

```bash
sudo usermod -aG sudo CAT
```

The user must start a new login session for the updated group membership to take effect.

### Challenge 4: Incorrect password attempts

**Problem:** Several sudo authentication attempts failed.

**Solution:** Reset the CAT password from the original administrator account:

```bash
sudo passwd CAT
```

When using sudo as CAT, enter CAT's password.

## 10. Commands Learned

| Command | Purpose |
|---|---|
| `useradd` | Creates a new user |
| `passwd` | Sets or changes a user's password |
| `su -` | Switches to another user |
| `whoami` | Displays the current username |
| `usermod -aG` | Adds a user to supplementary groups |
| `groups` | Displays a user's group memberships |
| `mkdir -p` | Creates directories |
| `chown` | Changes file or directory ownership |
| `sudo` | Executes commands with elevated privileges |
