

## Objective
To determine how long a Linux system has been running and examine its system load averages.

## 1. Checking System Uptime

Command:

```bash
uptime
```

**Explanation:**

The `uptime` command displays:
- Current system time.
- How long the system has been running.
- Number of logged-in users.
- Load averages over 1, 5 and 15 minutes.

## 2. Understanding Load Averages

Linux displays three load average values:

| Period | Meaning |
|---|---|
| 1 minute | Average system load over the last minute. |
| 5 minutes | Average system load over the last five minutes. |
| 15 minutes | Average system load over the last fifteen minutes. |

Load average represents the average number of tasks running or waiting for CPU time, including certain tasks waiting for other system resources.

## 3. Displaying Uptime in Human-Readable Format

Command:

```bash
uptime -p
```

**Explanation:**

The `-p` option displays system uptime in a simplified, human-readable format.

## 4. Key Learnings

- `uptime` displays system uptime and load averages.
- `uptime -p` displays uptime in a readable format.
- Load averages help monitor system workload.
- The three load averages represent 1-minute, 5-minute and 15-minute periods.

## Conclusion

The lab demonstrated how to use Linux uptime commands to monitor system running time and understand load averages.
