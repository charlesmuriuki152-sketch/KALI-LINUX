BACKGROUND: LINUX SOFTWARE MANAGEMENT

Software management is an essential part of using and maintaining a Linux system.

Many Linux distributions provide centralized software repositories. These repositories contain software packages that users can search for and install using graphical or command-line tools.

A software management tool helps users:

- Browse available applications.
- View installed applications.
- Search for applications by name.
- Explore applications by category.
- Read application descriptions.
- Review available software versions and other details.
- Install, update, or remove software when necessary.

Linux systems use different command-line package managers. For example, APT is used on Debian-based distributions, while DNF is used on Fedora.

This lab focused on exploring applications through the Kali Linux graphical desktop and using terminal commands to search for and inspect software packages.

OPTIONAL: EXPLORING APPLICATIONS THROUGH THE TERMINAL

Linux provides command-line utilities for inspecting installed packages and searching for available software.

On Kali Linux, the following commands can be used.

List installed packages:
apt list --installed

Search for a package:
apt search package-name

Check whether a package is installed:
dpkg -l package-name

Display package information:
apt show package-name
