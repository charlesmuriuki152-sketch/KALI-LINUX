

## Overview
This lab explores installed applications and discovers additional software using Kali Linux software management tools.

## Objectives
- Explore applications available on Kali Linux.
- Review application categories.
- Search for software that is not installed.
- Examine package information without installing software.

## Environment

- Operating System: Kali Linux
- Desktop Environment: XFCE
- Remote Access: XRDP
- Package Manager: APT
- Interface: Graphical Desktop and Terminal
