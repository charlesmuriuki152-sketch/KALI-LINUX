## 📚 Background: Linux Software Management

Software management is an essential part of using and maintaining a Linux system.

Unlike systems where applications are commonly downloaded from individual websites, many Linux distributions provide centralized software repositories. These repositories contain software packages that can be searched for and installed using graphical or command-line tools.

A software management tool helps users:

* Browse available applications.
* View installed applications.
* Search for applications by name.
* Explore applications by category.
* Read application descriptions.
* Review available software versions and other details.
* Install, update, or remove software when necessary.

Linux systems may also use command-line package managers, such as APT on Debian-based distributions and DNF on Fedora-based distributions.

This lab focused on exploring software through the graphical interface rather than installing applications through the terminal.

## 💻 Optional: Exploring Applications Through the Terminal

Although this lab focused on the graphical software management tool, Linux also provides command-line utilities for inspecting installed packages.

The following commands are optional and depend on your Linux distribution.

### Ubuntu, Debian, and Linux Mint

List installed packages using APT:

```bash
apt list --installed
```

Search for a package in the configured APT repositories:

```bash
apt search package-name
```

Replace `package-name` with the name of the application or package you want to search for.

### Fedora

List installed packages using DNF:

```bash
dnf list --installed
```

Search for an available package:

```bash
dnf search package-name
```

### Arch Linux

List explicitly installed packages:

```bash
pacman -Qe
```

Search for a package in the configured repositories:

```bash
pacman -Ss package-name
```

**Important:** These commands are provided for additional learning. They are not required to complete the graphical lab, and commands from one distribution may not work on another.

The optional commands above only inspect or search for software; they do not install packages.

## 🔐 Security Considerations

Software management is also important for maintaining a secure Linux environment.

When exploring or installing software, it is good practice to:

* Prefer trusted distribution repositories and reputable software sources.
* Review an application's purpose before installing it.
* Check the publisher or package source when that information is available.
* Keep installed software updated.
* Avoid installing unfamiliar packages from untrusted sources.

These practices help reduce the risk of installing unwanted or potentially malicious software.
