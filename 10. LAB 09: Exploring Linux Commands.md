# Linux Lab 8.3: Exploring Command Documentation

## 1. Introduction

This lab explores two ways of accessing documentation and available options for Linux commands.

The practical exercise uses the `mkdir` command to understand how to find information about Linux commands using `--help` and `man`.

## 2. Lab Objectives

- Understand how to access Linux command documentation.
- Learn how to use the `--help` option.
- Learn how to access manual pages using `man`.
- Identify the available options supported by the `mkdir` command.
- Understand the difference between short and long command options.

## 3. Tools and Environment

- **Operating System:** Kali Linux
- **Terminal:** Linux Bash Terminal
- **Command:** mkdir
- **Documentation tools:** --help and man

## 4. Challenge Encountered

While learning Linux commands, I needed to identify the available options supported by the `mkdir` command.

The challenge was understanding how to access command documentation and distinguish between the different methods available in Linux.

## 5. Practical Implementation

### Step 1: Accessing command help

I executed the following command in the Kali Linux terminal:

```bash
mkdir --help
```

**Observation:**

The terminal displayed a list of available options for the `mkdir` command, together with brief explanations of what each option does.

Some of the options displayed included:

| Option | Description |
|---|---|
| `-m, --mode` | Set directory permissions. |
| `-p, --parents` | Create parent directories when needed. |
| `-v, --verbose` | Display a message for each created directory. |
| `--help` | Display help information. |
| `--version` | Display version information. |

### Step 2: Accessing the manual page

I then executed:

```bash
man mkdir
```

**Observation:**

The command opened the manual page for `mkdir`.

Unlike `mkdir --help`, the manual provides more detailed documentation, explaining the command, its options, and how they are used.

I used the `q` key to exit the manual page and return to the terminal.

## 6. Comparison of Documentation Methods

| Feature | mkdir --help | man mkdir |
|---|---|---|
| Information | Quick summary | Detailed documentation |
| Display | Directly in terminal | Opens a manual viewer |
| Purpose | Quick reference | In-depth understanding |
| Exit | Returns to terminal | Press `q` |

## 7. Results

The practical exercise was successfully completed.

I was able to:

- Display the available options for `mkdir` using `mkdir --help`.
- Access the full manual page using `man mkdir`.
- Identify several options supported by the command.
- Understand that Linux provides different ways of accessing command documentation.

## 8. Conclusion

This lab helped me understand how to find information about Linux commands without having to memorize all their options.

I learned that `--help` is useful for quickly viewing available options, while `man` provides more detailed documentation.

These documentation skills are important when working with Linux systems, particularly in system administration and cybersecurity.
