

## 1. Introduction

Linux provides several ways of accessing system documentation. Apart from using terminal-based commands such as `man` and `info`, Linux also supports graphical documentation viewers.

In this lab, I explored the graphical Help system in Kali Linux using **Yelp**, a graphical documentation browser. I used it to locate and view the manual page for the `printf` command.

## 2. Objective

- Identify and launch the graphical Help system in Kali Linux.
- Learn how to access Linux manual pages through a graphical interface.
- Locate and read the `printf` manual page using Yelp.
- Understand how graphical documentation viewers simplify access to Linux documentation.

## 3. Tools and Requirements

| Tool | Purpose |
|---|---|
| Kali Linux | Operating system used for the lab |
| Terminal | Executing the command to launch Yelp |
| Yelp | Graphical Help and documentation viewer |
| `printf` | Command whose manual page was accessed |

## 4. Practical Procedure

### Step 1: Open the Kali Linux Terminal

I launched the Kali Linux terminal to execute the command required to open the graphical Help browser.

### Step 2: Launch Yelp and Locate the printf Manual

I executed the following command:

```bash
yelp man:printf
```

**Command breakdown:**

- `yelp`: Launches the graphical Help browser.
- `man:`: Specifies that the requested documentation is a manual page.
- `printf`: Specifies the manual page to display.

### Step 3: View the printf Manual Page

After executing the command, the Yelp graphical Help window opened and displayed the `printf` manual page.

The documentation contained several sections, including:

- **NAME:** Identifies the command and briefly explains its purpose.
- **SYNOPSIS:** Shows the command's general syntax and usage.
- **DESCRIPTION:** Explains how the command operates.
- **OPTIONS:** Provides information about available command options.

This confirmed that the graphical documentation viewer could successfully access Linux manual pages.

## 6. Alternative Method

If Yelp is already running, its location bar can be used to navigate directly to another manual page.

Procedure:

1. Open Yelp.
2. Press `Ctrl + L` to activate the location bar.
3. Enter the manual page address:

```text
man:ls
```

4. Press Enter to display the manual page for `ls`.

The same approach can be used to access documentation for other Linux commands.
