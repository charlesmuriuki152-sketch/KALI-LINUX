

## 1. Overview

This practical lab demonstrates how to create a compressed backup of a Linux home directory, inspect the archive without extracting it, and restore the backed-up files into a separate directory.

I performed this exercise using Kali Linux running on WSL2.

The main tools used were `tar` and `gzip`.

## 2. Objectives

The objectives of this lab were to:

- Navigate to the `/tmp` directory.
- Create a GZIP-compressed archive of my home directory.
- List archive contents without extracting them.
- Create a separate restoration directory.
- Extract the backup into the restoration directory.
- Verify that the restored files were present.

## 3. Step 1: Navigate to the /tmp Directory

I started by navigating to the `/tmp` directory, where I would store my temporary backup archive.

**Command:**

```bash
cd /tmp
```

To confirm my current location, I used:

```bash
pwd
```

**Expected output:**

```text
/tmp
```

**Explanation:**

- `cd` means change directory.
- `/tmp` is a Linux directory used for temporary files.
- `pwd` displays the current working directory.

## 4. Step 2: Create a GZIP-Compressed Backup

I created a compressed archive of my home directory using the `tar` command.

**Command:**

```bash
tar -czvf backup.tar.gz -C /home charles
```

**Explanation of the options:**

| Option | Meaning |
|---|---|
| `tar` | Archive management utility. |
| `-c` | Creates a new archive. |
| `-z` | Compresses the archive using GZIP. |
| `-v` | Displays the files being processed. |
| `-f` | Specifies the archive filename. |
| `backup.tar.gz` | Name of the backup archive. |
| `-C /home` | Changes to `/home` before archiving. |
| `charles` | The home directory being backed up. |

**Expected result:**

The command creates:

```text
/tmp/backup.tar.gz
```

The archive contains the files and directories inside `/home/charles`.

## 5. Step 3: List Archive Contents Without Extracting

After creating the backup, I inspected its contents without extracting any files.

**Command:**

```bash
tar -tzf backup.tar.gz
```

To display only the first 20 entries, I used:

```bash
tar -tzf backup.tar.gz | head -20
```

**Explanation:**

- `-t` lists archive contents.
- `-z` handles GZIP compression.
- `-f` specifies the archive filename.
- `head -20` displays the first 20 entries.

**Expected output:**

```text
charles/
charles/.bashrc
charles/.profile
charles/.bash_logout
...
```

**Observation:**

The command successfully displays the files stored inside the compressed archive without extracting them.

This allows me to inspect a backup before restoring its contents.

## 6. Step 4: Create a Restoration Directory

I created a new directory under `/tmp` to hold the restored files.

**Command:**

```bash
mkdir /tmp/restore
```

To verify that the directory was created, I used:

```bash
ls -ld /tmp/restore
```

**Explanation:**

- `mkdir` creates a directory.
- `/tmp/restore` is the destination for the restored files.
- `ls -ld` displays information about the directory itself.

## 7. Step 5: Extract the Backup

I extracted the compressed archive into the newly created restoration directory.

**Command:**

```bash
tar -xzf backup.tar.gz -C /tmp/restore
```

**Explanation of the options:**

| Option | Meaning |
|---|---|
| `-x` | Extracts archive contents. |
| `-z` | Decompresses GZIP data. |
| `-f` | Specifies the archive filename. |
| `-C` | Specifies the destination directory. |

The `-C /tmp/restore` option ensures that the files are extracted into the restoration directory rather than overwriting the original home directory.

## 8. Step 6: Verify the Restored Files

Finally, I checked whether the files had been successfully restored.

**Command:**

```bash
ls /tmp/restore/charles
```

To include hidden files and directories, I used:

```bash
ls -la /tmp/restore/charles
```

**Expected result:**

The output should display files and directories originally contained in my home directory.

This confirms that the backup archive was successfully extracted.

## 9. Challenges Encountered

One important consideration when performing this exercise is understanding the different options used with `tar`.

Initially, the combination of `-c`, `-x`, `-t` and `-z` can be confusing.

I learned that:

- `-c` creates an archive.
- `-t` lists archive contents.
- `-x` extracts archive contents.
- `-z` enables GZIP compression or decompression.

Understanding these options makes it easier to create, inspect and restore backups.

## 11. Key Lessons Learned

1. Linux provides tools for creating and managing backups.
2. `tar` can combine multiple files and directories into one archive.
3. `gzip` compresses data to reduce storage requirements.
4. Archive contents can be inspected without extracting them.
5. Backups can be restored into a separate directory.
6. Restoring files into a different location helps avoid accidentally overwriting the original files.

## 12. Conclusion

This practical exercise improved my understanding of Linux backup and restoration procedures.

I learned how to create a GZIP-compressed archive of my home directory, inspect its contents without extraction, and restore the archived files into a separate directory.

These skills are important in Linux system administration, data protection and cybersecurity because reliable backups help maintain data availability and support recovery when data is lost or damaged.
