

## 1. Overview

This lab explores how Linux identifies different file types using the `file` command. It also demonstrates that changing a file's extension does not necessarily change its actual format.

The practical exercises were performed in Kali Linux using the `/tmp` directory.

## 2. Objectives

By completing this lab, I aimed to:

- Identify different file types using the `file` command.
- Understand how Linux distinguishes text files, executable programs and directories.
- Learn how file identification works independently of filename extensions.
- Copy and rename an image file.
- Verify the actual format of a renamed image.

## 3. Working Directory

I started by navigating to the `/tmp` directory.

```bash
cd /tmp
```

I verified my current working directory using:

```bash
pwd
```

Expected output:

```text
/tmp
```

## 4. Finding an Existing Image File

Initially, I checked my Downloads directory for available images.

```bash
ls ~/Downloads
```

The command returned no output, indicating that there were no visible files in the directory.

I therefore searched the `/usr/share` directory for existing PNG and JPEG images.

```bash
find /usr/share -type f \( -iname "*.png" -o -iname "*.jpg" -o -iname "*.jpeg" \) 2>/dev/null | head
```

The search returned several image files, including:

```text
/usr/share/xrdp/xrdp_logo.png
/usr/share/gtk-doc/html/libtasn1/home.png
/usr/share/gtk-doc/html/libtasn1/up-insensitive.png
/usr/share/gtk-doc/html/libtasn1/right-insensitive.png
```

I selected the XRDP logo image for the exercise.

## 5. Copying the Image into /tmp

I copied the selected image into my working directory and renamed the destination file `sample.png`.

```bash
cp /usr/share/xrdp/xrdp_logo.png /tmp/sample.png
```

**Explanation:**

- `cp` is used to copy files.
- `/usr/share/xrdp/xrdp_logo.png` is the original image.
- `/tmp/sample.png` is the copied image.

## 6. Testing Extension Independence

Next, I renamed the copied image from `sample.png` to `sample.txt`.

```bash
mv sample.png sample.txt
```

**Explanation:**

- `mv` is used to move or rename files.
- `sample.png` is the original filename.
- `sample.txt` is the new filename.

Changing the extension to `.txt` does not convert the image into a text file. Only its filename has changed.

## 7. Identifying the Actual File Type

I used the `file` command to inspect the renamed image.

```bash
file sample.txt
```

**Expected output:**

```text
sample.txt: PNG image data, ...
```

The exact output may contain additional information about the image.

**Observation:**

Although the file was renamed with a `.txt` extension, Linux correctly identified it as PNG image data.

This demonstrates that the `file` utility examines the internal contents and identifying signatures of a file instead of relying only on its extension.

## 8. Verifying the Renamed File

I confirmed that the renamed file existed in `/tmp`.

```bash
ls -l sample.txt
```

This displayed the file's details, including its filename, permissions, size and modification time.

## 9. Challenge Encountered

**Challenge:** My Downloads directory did not contain any visible image files.

**Solution:** Instead of downloading an image, I used the Linux `find` command to search the `/usr/share` directory for existing PNG and JPEG files.

I selected `/usr/share/xrdp/xrdp_logo.png` and used it to complete the exercise.

## 10. Key Commands Learned

| Command | Purpose |
|---|---|
| `cd /tmp` | Changes into the temporary directory. |
| `pwd` | Displays the current working directory. |
| `ls` | Lists directory contents. |
| `find` | Searches for files and directories. |
| `cp` | Copies files. |
| `mv` | Moves or renames files. |
| `file` | Identifies the actual file type. |
| `ls -l` | Displays detailed file information. |

## 11. Key Lessons Learned

1. Linux can identify different file types by examining their internal contents.
2. A filename extension does not guarantee the actual file format.
3. The `file` command can identify text files, executable programs, directories and image files.
4. The `cp` command creates copies without modifying the original file.
5. The `mv` command can rename a file without converting its format.
6. File signatures help Linux recognize different file formats.

## 12. Conclusion

This practical exercise helped me understand how Linux identifies files based on their actual contents rather than simply trusting their filenames.

By copying an existing PNG image, renaming it with a `.txt` extension and inspecting it using the `file` command, I demonstrated that Linux could still recognize the file as PNG image data.

The exercise improved my understanding of Linux file management, file identification and command-line operations.
