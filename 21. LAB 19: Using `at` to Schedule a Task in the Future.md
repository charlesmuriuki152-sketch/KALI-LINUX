

## Objective

To learn how to schedule one-time tasks for future execution in Linux using the `at` command, both from a script and interactively.

## 1. Installing and Configuring `at`

Install the `at` package:

```bash
sudo apt update
sudo apt install at -y
```

Start the background scheduling service:

```bash
sudo service atd start
```

Check the service status:

```bash
sudo service atd status
```

Check the installed version:

```bash
at -V
```

**Observation:**
- `at` version 3.2.5 was installed successfully.
- The `atd` service was active and running.
- The scheduler was ready to execute scheduled jobs.

## 2. Method 1 — Scheduling From a Script

### Step 1: Create the script

```bash
nano testat.sh
```

Script contents:

```bash
#!/bin/bash
date > /tmp/datestamp
```

**Explanation:**
- `#!/bin/bash` tells Linux to use Bash as the script interpreter.
- `date` displays the current date and time.
- `>` redirects the output into a file.
- `/tmp/datestamp` is the destination file.

Save the file using `Ctrl + O`, press Enter, and exit using `Ctrl + X`.

### Step 2: Schedule the script

```bash
at now + 1 minute -f testat.sh
```

The `-f` option tells `at` to execute commands from the specified script file.

### Step 3: Check scheduled jobs

```bash
atq
```

This displays jobs waiting in the scheduling queue.

### Step 4: Verify execution

After approximately one minute, run:

```bash
cat /tmp/datestamp
```

The command displays the date and time saved by the scheduled script.

## 3. Method 2 — Scheduling Interactively

This method schedules a command without creating a script file.

### Step 1: Open the interactive scheduler

```bash
at now + 1 minute
```

The terminal displays an `at>` prompt.

### Step 2: Enter the command

```bash
date > /tmp/datestamp
```

### Step 3: Submit the job

Press:

```text
Ctrl + D
```

`Ctrl + D` signals the end of the input (EOT) and submits the scheduled job.

### Step 4: Check the queue

```bash
atq
```

### Step 5: Verify execution

```bash
cat /tmp/datestamp
```

The file contains the date and time generated by the scheduled command.

## 4. Exploring: Where Does the Output Go?

When scheduling a command without output redirection, `at` captures its output and attempts to send it through the local mail system.

Example:

```bash
at now + 1 minute
```

At the `at>` prompt, enter:

```bash
date
```

Press `Ctrl + D` to submit the job.

Check scheduled jobs:

```bash
atq
```

After the scheduled execution, inspect the local mailbox:

```bash
cat /var/mail/$USER
```

**Actual observation:**

```text
cat: /var/mail/charles: No such file or directory
```

This indicates that the expected local mailbox was not available on my Kali installation. A local mail delivery service may not be configured.

This does not necessarily indicate that the scheduled command failed.

## 5. Understanding the `at` Output

Example:

```text
6 16:04:00 2026 a charles
```

| Element | Meaning |
|---|---|
| `6` | Job identification number |
| `16:04:00` | Scheduled execution time |
| `2026` | Execution year |
| `a` | Queue name |
| `charles` | User who scheduled the job |

## 6. Important Commands

| Command | Function |
|---|---|
| `sudo apt install at -y` | Installs the at package |
| `sudo service atd start` | Starts the scheduling service |
| `sudo service atd status` | Checks service status |
| `at -V` | Displays the installed version |
| `at now + 1 minute` | Schedules a task one minute ahead |
| `at -f testat.sh` | Executes a scheduled script |
| `atq` | Lists queued jobs |
| `cat /tmp/datestamp` | Displays saved output |
| `cat /var/mail/$USER` | Checks the local mailbox |
| `Ctrl + D` | Submits interactive job input |

## 7. Key Learnings

- `at` schedules one-time tasks for future execution.
- `atd` is the background service responsible for executing scheduled jobs.
- Tasks can be scheduled using scripts or interactively.
- `atq` displays pending scheduled jobs.
- `Ctrl + D` submits commands entered at the interactive prompt.
- Without redirection, command output is captured and sent through the local mail system when available.
- Output redirection using `>` provides a reliable way to save results directly into a file.
