

## Lab Exercise

### Objective

Write a Bash script that acts as a simple calculator capable of performing four mathematical operations:

- Addition
- Subtraction
- Multiplication
- Division

Each mathematical operation must have its own function.

The user must provide three command-line arguments when executing the script:

1. An operation letter:
   - `a` – Addition
   - `s` – Subtraction
   - `m` – Multiplication
   - `d` – Division
2. First number.
3. Second number.

The script must detect invalid or missing input values and display the calculation results.

---

## 1. Creating the Script

Create a file named `calculator.sh`.

```bash
nano calculator.sh
```

## 2. Script Implementation

```bash
#!/bin/bash

# Function for addition
addition() {
    echo "Result: $(($2 + $3))"
}

# Function for subtraction
subtraction() {
    echo "Result: $(($2 - $3))"
}

# Function for multiplication
multiplication() {
    echo "Result: $(($2 * $3))"
}

# Function for division
division() {
    if [ "$3" -eq 0 ]; then
        echo "Error: Division by zero is not allowed."
    else
        echo "Result: $(($2 / $3))"
    fi
}

# Check number of arguments
if [ "$#" -ne 3 ]; then
    echo "Usage: $0 [a|s|m|d] number1 number2"
    exit 1
fi

# Validate numerical arguments
if ! [[ "$2" =~ ^-?[0-9]+$ && "$3" =~ ^-?[0-9]+$ ]]; then
    echo "Error: Please enter valid integers."
    exit 1
fi

# Select mathematical operation
case "$1" in
    a)
        addition "$@"
        ;;
    s)
        subtraction "$@"
        ;;
    m)
        multiplication "$@"
        ;;
    d)
        division "$@"
        ;;
    *)
        echo "Error: Invalid operation."
        echo "Use a, s, m, or d."
        exit 1
        ;;
esac
```

## 3. Making the Script Executable

Run:

```bash
chmod +x calculator.sh
```

## 5. Testing Error Handling

### Missing Arguments

```bash
./calculator.sh a 10
```

Expected output:
```text
Usage: ./calculator.sh [a|s|m|d] number1 number2
```

### Invalid Operation

```bash
./calculator.sh x 10 5
```

Expected output:
```text
Error: Invalid operation.
Use a, s, m, or d.
```

### Invalid Numerical Input

```bash
./calculator.sh a hello 5
```

Expected output:
```text
Error: Please enter valid integers.
```

### Division by Zero

```bash
./calculator.sh d 10 0
```

Expected output:
```text
Error: Division by zero is not allowed.
```

## 6. Bash Concepts Learned

| Concept | Description |
|---|---|
| Functions | Used to organize each mathematical operation separately. |
| `$1`, `$2`, `$3` | Access command-line arguments. |
| `$#` | Counts the arguments supplied to a script. |
| `$@` | Passes all supplied arguments to a function. |
| `if` statement | Checks conditions and validates input. |
| `case` statement | Selects the appropriate mathematical operation. |
| `$(( ))` | Performs arithmetic calculations. |
| `exit 1` | Terminates the script with an error status. |
| Regular expressions | Validate integer input. |

## 7. Challenges and Error Handling

The script includes several input validation mechanisms:

- Detects when fewer or more than three arguments are supplied.
- Rejects invalid mathematical operation letters.
- Rejects non-integer numerical arguments.
- Prevents division by zero.
- Displays appropriate error messages.

**Note:** Division uses integer arithmetic, meaning decimal remainders are discarded.
