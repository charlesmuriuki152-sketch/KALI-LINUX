## 1. Objective
To practise basic file editing using Vim, including inserting text, deleting lines, undoing changes, saving and exiting.

## 2. Tools Used
- Kali Linux
- Vim text editor
- Linux terminal
- `cat` command

## 3. Procedure

### Step 1: Open a New File

```bash
vi /tmp/vitest.txt
```

This opened a new file called `vitest.txt` in the `/tmp` directory.

### Step 2: Insert Text

Pressed `i` to enter Insert mode and typed:

```text
My Linux Learning Journey

I am learning the Vi editor.
I am practising basic Linux commands.
I am developing my cybersecurity skills.
```

### Step 3: Delete and Undo a Line

Pressed `Esc` to return to Normal mode.

Executed:

```vim
dd
```

This deleted the current line.

Then executed:

```vim
u
```

This restored the deleted line.

### Step 4: Save and Exit

Executed:

```vim
:wq
```

This saved the file and exited Vim.

### Step 5: Verify File Contents

Executed:

```bash
cat /tmp/vitest.txt
```

The terminal displayed the saved text, confirming that the file was successfully created and the deleted line had been restored.

## 4. Commands Learned

| Command | Function |
|---|---|
| `vi /tmp/vitest.txt` | Opens or creates a file |
| `i` | Enters Insert mode |
| `Esc` | Returns to Normal mode |
| `dd` | Deletes the current line |
| `u` | Undoes the last change |
| `:wq` | Saves and exits |
| `cat` | Displays file contents |

## 5. Challenges Encountered

Initially, an incorrect file path (`/temp/` instead of `/tmp/`) caused a file-saving issue. Correcting the path resolved the mistake.

## 6. Results

- Successfully created `vitest.txt`.
- Entered text using Insert mode.
- Deleted and restored a line.
- Saved and exited using `:wq`.
- Verified the saved contents using `cat`.

## 7. Conclusion

This lab provided practical experience with basic Vim editing operations. I learned how to manage text using keyboard commands without relying on a graphical text editor.
