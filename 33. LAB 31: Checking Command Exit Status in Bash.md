

## Objective

Write and execute a Bash shell script that checks the exit status of the `ls` command under two different conditions:

1. Attempting to list a file that does not exist.
2. Creating a file and successfully listing it.

The exercise demonstrates how Bash uses exit statuses to indicate whether commands execute successfully or encounter errors.

## 1. Creating the Script

Created a file named `testls.sh`:

```bash
nano testls.sh
```

## 2. Script Content

```bash
#!/bin/bash

#
# Check for a non-existent file
#

ls somefile
echo "status: $?"

# Create the file
touch somefile

# List the file
ls somefile
echo "status: $?"

# Remove the file to clean up
rm somefile
```

## 3. Making the Script Executable

Used the `chmod` command to grant execute permission:

```bash
chmod +x testls.sh
```

## 4. Executing the Script

Ran the script using:

```bash
./testls.sh
```

## 5. Expected Output

```text
ls: cannot access 'somefile': No such file or directory
status: 2
somefile
status: 0
```

## 6. Explanation of Commands

| Command | Description |
|---|---|
| `#!/bin/bash` | Specifies Bash as the script interpreter. |
| `ls somefile` | Attempts to list the specified file. |
| `echo "$?"` | Displays the exit status of the previous command. |
| `touch somefile` | Creates an empty file named `somefile`. |
| `rm somefile` | Removes the test file. |
| `chmod +x` | Grants execute permission to the script. |

## 7. Understanding Exit Status

In Bash, `$?` is a special variable that stores the exit status of the most recently executed command.

- **Exit status 0:** The command completed successfully.
- **Exit status 2:** The `ls` command encountered an error because the requested file could not be accessed.

### Why Did the Exit Status Change?

**First execution:**

```bash
ls somefile
```

The file does not exist, so `ls` returns exit status `2`.

**Second execution:**

```bash
touch somefile
ls somefile
```

The `touch` command creates the file. The subsequent `ls` command finds it successfully and returns exit status `0`.
