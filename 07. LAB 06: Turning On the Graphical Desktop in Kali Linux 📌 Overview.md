

## 📌 Overview

This lab demonstrates how to set up and launch a graphical desktop environment in Kali Linux installed through the Microsoft Store using Windows Subsystem for Linux (WSL).

Initially, Kali Linux runs in a terminal environment, where users interact with the operating system by typing commands. By installing Win-KeX, we can access a graphical desktop with windows, menus, icons, and a mouse-driven interface.

## 🎯 Objectives

* Understand the difference between text mode and graphical mode.
* Update Kali Linux packages.
* Install Win-KeX.
* Launch the Kali Linux graphical desktop.
* Understand how graphical environments work in WSL.

## 🛠️ Environment

* **Operating System:** Windows
* **Linux Distribution:** Kali Linux
* **Linux Environment:** Windows Subsystem for Linux (WSL)
* **Graphical Desktop Tool:** Win-KeX
* **Installation Source:** Microsoft Store

## 🚀 Step 1: Open Kali Linux

Launch the Kali Linux application from the Microsoft Store installation.

The terminal provides a command-line interface for interacting with Kali Linux.

## 🔄 Step 2: Update Package Lists

Run the following command:

```bash
sudo apt update
```

This command refreshes the local package lists so Kali Linux can identify available package updates.

## 🖥️ Step 3: Install Win-KeX

Install the Win-KeX package using:

```bash
sudo apt install -y kali-win-kex
```

**Explanation:**

* `sudo` runs the command with administrator privileges.
* `apt install` installs the requested package.
* `-y` automatically confirms installation prompts.
* `kali-win-kex` provides graphical desktop integration for Kali Linux on WSL.

Wait for the installation to complete.

## ▶️ Step 4: Launch the Graphical Desktop

Run the following command:

```bash
kex --win -s
```

This launches the Win-KeX graphical desktop in a separate window.

On the first launch, you may be prompted to configure a VNC password.

After successful startup, the Kali Linux graphical desktop becomes available, allowing interaction through windows, menus, icons, and a mouse.

## 🧠 Understanding Text Mode vs. Graphical Mode

| Text Mode                                        | Graphical Mode                                        |
| ------------------------------------------------ | ----------------------------------------------------- |
| Primarily uses a command-line interface.         | Uses windows, icons, menus, and a mouse.              |
| Commands are entered using a keyboard.           | Applications can be opened through graphical menus.   |
| Commonly used for administration and automation. | Convenient for desktop applications and visual tools. |
| Example: Kali Linux terminal.                    | Example: Kali Linux desktop launched through Win-KeX. |

## ⚠️ Important Note About WSL

Kali Linux installed through the Microsoft Store commonly runs under WSL, rather than as a full standalone Linux installation.

Therefore, commands such as:

```bash
sudo systemctl isolate multi-user.target
```

and:

```bash
sudo systemctl isolate graphical.target
```

may not work as expected in a standard WSL environment.

These commands switch systemd targets on Linux systems that support the relevant systemd configuration. Win-KeX provides a separate approach for running a graphical Kali desktop under WSL.
