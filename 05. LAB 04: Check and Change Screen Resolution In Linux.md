
## 1. OBJECTIVE

The objective of this lab is to identify the current screen resolution in a Linux desktop environment, inspect available display modes, and understand how to change and restore the screen resolution using graphical settings and terminal commands.

## 2. ENVIRONMENT

- Operating System: Kali Linux
- Course: Introduction to Linux (LFS101)
- Lab: Lab 5.1 — Screen Resolution
- Terminal utilities: xdpyinfo and xrandr
- Display environment: Remote Desktop Connection

## 3. INTRODUCTION

Screen resolution refers to the number of pixels displayed horizontally and vertically on a screen.

For example, a resolution of 1920 × 1200 means that the screen displays 1920 horizontal pixels and 1200 vertical pixels.

Linux provides graphical tools and command-line utilities for checking and changing display resolution.

The `xdpyinfo` command displays information about the active X display, while `xrandr` lists connected displays and available resolutions.

Before changing a screen resolution, it is important to record the original setting so it can be restored after the exercise.

## 4. PROCEDURE

### Step 1: Open the Display Settings

The Linux desktop provides access to display settings through the graphical interface.

Depending on the Linux distribution, display settings can be accessed through:

- Settings → Displays
- Settings → Devices → Displays

Alternatively, right-click the desktop and select Display Settings.

The current resolution should be recorded before making changes.

### Step 2: Check the Current Screen Resolution

Open the terminal and execute the following command:

```bash
xdpyinfo | grep dim
```

This command displays the dimensions of the current X display.

Observed output:

```text
dimensions: 1920x1200 pixels (508x318 millimeters)
```

The output indicates that the current screen resolution is 1920 × 1200 pixels.

### Step 3: Check Available Display Modes

Execute the following command:

```bash
xrandr --query
```

This command displays connected monitors, the current resolution, and available display modes.

Observed output from the supplied screenshot:

```text
Screen 0: minimum 256 x 256, current 1920 x 1200, maximum 16384 x 16384
rdp0 connected 1920x1200+0+0 508mm x 318mm
   1920x1200 50.00*
```

The output shows that:

- The connected display is identified as `rdp0`.
- The current resolution is 1920 × 1200 pixels.
- The active display mode is marked with an asterisk (*).
- The displayed refresh rate is 50 Hz.

### Step 4: Change the Screen Resolution

To change the screen resolution:

1. Open the Linux desktop Settings.
2. Select Displays.
3. Locate the Resolution dropdown.
4. Select an available resolution supported by the display.
5. Apply the change and confirm it if prompted.

The original resolution should be recorded before making changes.

Note: The supplied screenshots demonstrate the resolution-checking commands but do not show a completed resolution change.

### Step 5: Verify the New Resolution

After changing the resolution, open the terminal and run:

```bash
xrandr --query
```

Check the current resolution and identify the active display mode.

You can also run:

```bash
xdpyinfo | grep dim
```

The output should reflect the currently active display dimensions.

### Step 6: Restore the Original Resolution

If the resolution was changed, open Settings → Displays and select the original resolution.

The original resolution recorded in this lab is:

**1920 × 1200 pixels**

Apply the setting and verify the restored resolution by running:

```bash
xrandr --query
```

The active display mode should show 1920 × 1200 pixels again.

Note: Restoring the original resolution should only be marked complete after the change has actually been performed and verified.
