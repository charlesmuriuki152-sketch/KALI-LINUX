

## 1. Objective

The objective of this exercise was to combine two separate PDF documents into one PDF using three different Linux utilities:

1. qpdf
2. pdftk (PDF Toolkit)
3. Ghostscript (gs)

The exercise also involved creating text files, converting them into PDFs, verifying the combined documents and viewing the final results.

## 6. Converting the Text Files into PDF Documents

I first converted the text files into PostScript documents using Enscript.

For the first document:

```bash
enscript -p file1.ps file1.txt
ps2pdf file1.ps file1.pdf
```

For the second document:

```bash
enscript -p file2.ps file2.txt
ps2pdf file2.ps file2.pdf
```

I verified the generated PDFs:

```bash
ls -lh *.pdf
```

The two source PDF documents were:

- `file1.pdf`
- `file2.pdf`

## 7. Method One: Combining PDFs Using qpdf

I used qpdf to combine the two PDF documents:

```bash
qpdf --empty --pages file1.pdf file2.pdf -- combined-qpdf.pdf
```

### Explanation

| Command | Purpose |
|---|---|
| `qpdf` | Runs the PDF manipulation utility. |
| `--empty` | Starts with an empty PDF document. |
| `--pages` | Specifies the source PDF pages. |
| `file1.pdf file2.pdf` | Specifies the two input documents. |
| `--` | Separates input arguments from the output argument. |
| `combined-qpdf.pdf` | Specifies the output document. |

I verified the resulting document:

```bash
pdfinfo combined-qpdf.pdf
```

## 8. Method Two: Combining PDFs Using pdftk

I used PDF Toolkit to concatenate the two documents:

```bash
pdftk file1.pdf file2.pdf cat output combined-pdftk.pdf
```

### Explanation

- `pdftk` runs the PDF Toolkit utility.
- `file1.pdf` and `file2.pdf` are the source documents.
- `cat` concatenates the documents.
- `output` specifies the output file.
- `combined-pdftk.pdf` is the resulting document.

I verified the result:

```bash
pdfinfo combined-pdftk.pdf
```

**Note:** If `pdftk` is unavailable, `pdftk-java` may be used as an alternative package.

## 9. Method Three: Combining PDFs Using Ghostscript

I used Ghostscript to combine the two PDF documents:

```bash
gs -dBATCH -dNOPAUSE -q -sDEVICE=pdfwrite -sOutputFile=combined-gs.pdf file1.pdf file2.pdf
```

### Explanation

| Option | Purpose |
|---|---|
| `gs` | Runs Ghostscript. |
| `-dBATCH` | Exits after processing. |
| `-dNOPAUSE` | Prevents pausing between pages. |
| `-q` | Suppresses routine messages. |
| `-sDEVICE=pdfwrite` | Selects PDF output. |
| `-sOutputFile=` | Specifies the output filename. |
| `file1.pdf file2.pdf` | Specifies the input documents. |

I verified the output:

```bash
pdfinfo combined-gs.pdf
```

## 10. Verifying the Combined PDF Documents

## 12. Comparison of the Three Methods

| Utility | Main Function | Output |
|---|---|---|
| qpdf | Combines PDF pages and documents. | combined-qpdf.pdf |
| pdftk | Concatenates PDF documents. | combined-pdftk.pdf |
| Ghostscript | Processes and generates combined PDFs. | combined-gs.pdf |

All three utilities can combine multiple PDF documents into one file.

However, the resulting files may differ in file size, metadata, internal structure and rendering characteristics.
