1. Introduction
In Linux, grep (Global Regular Expression Print) is a command-line utility used to search for specific words, strings, and patterns in files.

It allows users to locate matching lines, filter command output, exclude unwanted results, and identify patterns using regular expressions.

In this lab, I used grep to search for usernames in /etc/passwd, find FTP-related entries in /etc/services, filter results based on the TCP protocol, exclude TCP entries, and identify strings using pattern matching.
2. Learning Objectives
By completing this lab, I learned how to:
1. Search for specific usernames in Linux files.
2. Find matching strings using grep.
3. Combine commands using pipelines.
4. Filter search results based on specific conditions.
5. Exclude matching lines using grep -v.
6. Display line numbers using grep -n.
7. Search for multiple patterns using grep -e.
8. Use regular expressions to match the beginning and end of lines.
3. Understanding the grep Command
The general syntax of grep is:
grep [options] "pattern" filename


Common grep options
Option	Function
-n	Displays matching lines with their line numbers.
-v	Displays lines that do not match the specified pattern.
-e	Allows multiple search patterns.
-i	Performs a case-insensitive search.
-r	Searches recursively through directories.

4. Step 1: Search for Your Username in /etc/passwd
The first task was to search for my username in the /etc/passwd file.

Command:
grep charles /etc/passwd


Explanation
- grep searches for matching text.
- charles is the username being searched for.
- /etc/passwd is the file being searched.
Expected Output
charles:x:1000:1000::/home/charles:/bin/bash


The output displays the account information for the matching username.

Observation: The command searches for the specified string and displays any line containing it.
5. Step 2: Find All Entries Containing ftp in /etc/services
The second task was to find all entries in /etc/services containing the string ftp.

Command:
grep ftp /etc/services


Explanation
- grep searches for matching text.
- ftp is the search pattern.
- /etc/services contains information about network services and their associated ports and protocols.
Expected Output
Some matching entries may include:
ftp-data        20/tcp
ftp             21/tcp
tftp            69/udp


The actual output depends on the contents of the system's /etc/services file.

Observation: The search returns every line containing the string ftp, including entries where it appears as part of a longer word.
6. Step 3: Filter FTP Entries That Use the TCP Protocol
The third task was to restrict the search results to entries that use the TCP protocol.

Command:
grep ftp /etc/services | grep tcp


Understanding the command
Component	Function
grep ftp /etc/services	Finds entries containing ftp.
\|	Sends the first command's output to the next command.
grep tcp	Filters the results to lines containing tcp.

Expected Output
ftp-data        20/tcp
ftp             21/tcp


Observation: Combining grep commands using a pipeline allows search results to be filtered further.
7. Step 4: Find FTP Entries That Do Not Use TCP and Display Line Numbers
The fourth task was to find FTP-related entries that do not use TCP while displaying their line numbers.

Command:
grep -n ftp /etc/services | grep -v tcp


Understanding the command
Component	Function
grep -n	Displays matching lines with their line numbers.
ftp	Specifies the search pattern.
/etc/services	Specifies the file being searched.
\|	Passes the output to another command.
grep -v tcp	Excludes lines containing tcp.

Expected Output
69:tftp           69/udp


The exact line number and output depend on the system's /etc/services file.

Observation: The -v option reverses the matching condition, allowing us to display lines that do not contain the specified pattern.

The -n option is useful when identifying the exact location of matching entries in a file.
8. Step 5: Find Strings That Start with ts or End with st
The final task was to find entries in /etc/services that either start with ts or end with st.

Command:
grep -e '^ts' -e 'st$' /etc/services


Understanding the command
Component	Function
grep	Searches for matching patterns.
-e	Specifies a search pattern.
^ts	Matches lines beginning with ts.
st$	Matches lines ending with st.
/etc/services	Specifies the file being searched.

Understanding the Regular Expression Symbols
Caret symbol (^)

Matches the beginning of a line.

Example:
grep '^ts' /etc/services


This finds lines beginning with ts.

Dollar symbol ($)

Matches the end of a line.

Example:
grep 'st$' /etc/services


This finds lines ending with st.

Multiple patterns using -e

The -e option allows multiple patterns to be specified in one command.

In this example:
grep -e '^ts' -e 'st$' /etc/services


A line is displayed if it matches either pattern.
9. Important Commands Summary
Command	Purpose
grep charles /etc/passwd	Searches for my username.
grep ftp /etc/services	Finds entries containing ftp.
grep ftp /etc/services \| grep tcp	Filters FTP entries using TCP.

grep -e '^ts' -e 'st$' /etc/services	Finds lines starting with ts or ending with st.
