

## Objective

To learn how to launch a graphical application from the Linux terminal and manage it as a foreground or background job.

## 1. Launching GNOME Calculator

Command:

```bash
gnome-calculator
```

**Explanation:**

- Launches GNOME Calculator.
- The application starts as a foreground job.
- The terminal remains occupied while the application runs in the foreground.

## 2. Suspending a Foreground Job

Shortcut:

```text
Ctrl + Z
```

**Explanation:**

Suspends the currently running foreground process and returns control to the terminal.

The Calculator window remains visible but becomes temporarily unusable because its process is stopped.

## 3. Listing Shell Jobs

Command:

```bash
jobs
```

**Explanation:**

Displays jobs started from the current shell, including their job numbers and states.

Example output:

```text
[1]+ Stopped    gnome-calculator
```

## 4. Resuming a Job in the Background

Command:

```bash
bg
```

**Explanation:**

Resumes the suspended job in the background, allowing the terminal to accept other commands while the application continues running.

## 5. Bringing a Job to the Foreground

Command:

```bash
fg
```

**Explanation:**

Brings the background job back to the foreground, allowing it to interact with the terminal as the active job.

## 6. Important Job Control Commands

| Command | Function |
|---|---|
| `gnome-calculator` | Launches GNOME Calculator |
| `Ctrl + Z` | Suspends the foreground job |
| `jobs` | Lists jobs in the current shell |
| `bg` | Resumes a suspended job in the background |
| `fg` | Brings a job to the foreground |
| `Ctrl + C` | Interrupts the foreground process |

## 7. Key Learnings

- A foreground job occupies the shell's foreground until it finishes or is suspended.
- A background job runs without occupying the shell's foreground.
- `Ctrl + Z` suspends a process; it does not terminate it.
- `bg` resumes a suspended job in the background.
- `fg` brings a job back to the foreground.
- Job numbers identify jobs managed by the current shell.

## Conclusion
