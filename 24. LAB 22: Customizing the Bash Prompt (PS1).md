
## Objective
Customize the Bash prompt to display the current directory, computer hostname, or both.

## 1. Display current working directory

```bash
export PS1='\w\$ '
```

`\w` displays the current working directory.

## 2. Display computer hostname

```bash
export PS1='\h\$ '
```

`\h` displays the computer hostname.

## 3. Display both

```bash
export PS1='\h:\w\$ '
```

Example:
```text
DESKTOP-LCFMHCU:~$
```

## 4. Make changes persistent

Open the Bash configuration file:

```bash
nano ~/.bashrc
```

Add this line at the bottom:

```bash
export PS1='\h:\w\$ '
```

Save using:
- `Ctrl + O`
- `Enter`
- `Ctrl + X`

Apply changes:

```bash
source ~/.bashrc
```

## Useful PS1 symbols

| Symbol | Meaning |
|---|---|
| `\h` | Computer hostname |
| `\w` | Current working directory |
| `\W` | Current directory name only |
| `\u` | Current username |
| `\$` | `$` for normal user, `#` for root |

## Conclusion

`PS1` controls the appearance of the Bash prompt. Adding its configuration to `~/.bashrc` makes the customization persistent for future interactive Bash sessions.
