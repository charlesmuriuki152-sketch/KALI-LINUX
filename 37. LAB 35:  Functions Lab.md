

## 1. Lab Overview

This lab focuses on defining and calling functions in Bash shell scripting.

The exercise involves writing a Bash script that prompts the user to enter a number (1, 2, or 3) and calls a corresponding function based on the number entered.

Each function displays a message containing its own name.

The lab also demonstrates how functions behave when a script is executed in a separate shell process.

## 2. Objectives

The objectives of this lab were to:

1. Write a Bash script containing three functions.
2. Prompt the user to enter a number between 1 and 3.
3. Call the appropriate function based on the user's input.
4. Display a message containing the name of the executed function.
5. Understand how functions are defined and called in Bash.
6. Understand the difference between executing a script and loading it into the current shell.

## 3. Creating the Script

A Bash script named `function.sh` was created using the Nano text editor.

Command used:

```bash
nano function.sh
```

### Script Contents

```bash
#!/bin/bash

# Define function 1
function1() {
    echo "You have called function1"
}

# Define function 2
function2() {
    echo "You have called function2"
}

# Define function 3
function3() {
    echo "You have called function3"
}

# Ask the user for a number
echo "Enter a number (1, 2 or 3):"
read num

# Call the corresponding function
case "$num" in
    1)
        function1
        ;;
    2)
        function2
        ;;
    3)
        function3
        ;;
    *)
        echo "Error: Please enter 1, 2 or 3."
        exit 1
        ;;
esac
```

## 4. Making the Script Executable

After creating and saving the script, executable permissions were granted using:

```bash
chmod +x function.sh
```

The script was executed using:

```bash
./function.sh
```

## 5. Understanding the Script

### A. Defining Functions

The following code defines the first function:

```bash
function1() {
    echo "You have called function1"
}
```

A function is a reusable block of code designed to perform a particular task.

In this example:

- `function1()` defines the function.
- The curly braces `{ }` contain the function instructions.
- `echo` displays the message when the function is called.

The same structure was used to define `function2()` and `function3()`.

### B. Accepting User Input

```bash
echo "Enter a number (1, 2 or 3):"
read num
```

The `echo` command displays a prompt, while `read` accepts the user's input and stores it in the variable `num`.

### C. Using the Case Statement

```bash
case "$num" in
```

The `case` statement evaluates the value entered by the user and determines which function should execute.

The corresponding function is called depending on the selected number.

### D. Calling Functions

For example:

```bash
1)
    function1
    ;;
```

When the user enters `1`, Bash executes `function1`.

Similarly:

- Input `2` calls `function2`.
- Input `3` calls `function3`.

### E. Handling Invalid Input

```bash
*)
    echo "Error: Please enter 1, 2 or 3."
    exit 1
    ;;
```

The wildcard `*` handles any input that does not match the specified options.

The script displays an error message and terminates with an error status.

## 7. Challenges Encountered

### Challenge: Calling a Function Directly from the Terminal

After successfully executing the script, an attempt was made to call `function1` directly from the terminal.

Command:

```bash
function1
```

Actual output:

```text
function1: command not found
```

The command was attempted again and returned the same error.

### Explanation

The error occurred because the functions were defined inside `function.sh`.

When the script was executed using:

```bash
./function.sh
```

Bash ran the script in a separate process. Once execution finished, the function definitions were no longer available in the original terminal shell.

### Solution: Using the source Command

To make the functions available in the current shell, the script can be loaded using:

```bash
source function.sh
```

After loading the script, the function can be called directly:

```bash
function1
```

Expected output:

```text
You have called function1
```

Other available functions can also be called:

```bash
function2
function3
```

**Important observation:** Using `source` executes the script in the current shell. Since this particular script also contains user input and a `case` statement, it will prompt for a number before returning to the terminal.

| `source` | Loads and executes a script in the current shell. |
