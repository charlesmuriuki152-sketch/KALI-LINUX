

## Objective
Understand how Linux uses the `PATH` environment variable to find and execute commands.

## 1. Create a fake ls program

```bash
echo "echo HELLO, this is the phony ls program." > /tmp/ls
```

## 2. Make it executable

```bash
chmod +x /tmp/ls
```

- `chmod` – changes file permissions.
- `+x` – adds execute permission.
- `/tmp/ls` – target file.

## 3. Append /tmp to PATH

```bash
export PATH=$PATH:/tmp
ls
```

**Result:** Normal `ls` runs because `/tmp` is searched last.

## 4. Prepend /tmp to PATH

```bash
export PATH=/tmp:$PATH
ls
```

**Result:**
```text
HELLO, this is the phony ls program.
```

## 5. Verify

```bash
which ls
```

Expected output:
```text
/tmp/ls
```

## Conclusion

Linux searches PATH directories from left to right.

- Append: `/tmp` goes last.
- Prepend: `/tmp` goes first.

**Key lesson:** PATH determines which executable runs when multiple programs have the same name.
