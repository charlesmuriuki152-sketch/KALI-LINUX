

## 1. Objective

The objective of this lab was to practise Linux document conversion using `enscript`, `ps2pdf`, and `pdfinfo`.

The exercise involved:

1. Checking whether the `enscript` package was installed and installing it if necessary.
2. Converting a text file into PostScript format.
3. Converting the PostScript document into PDF format.
4. Performing direct text-to-PDF conversion without saving an intermediate PostScript file.
5. Using `pdfinfo` to inspect PDF metadata.

## 2. Tools and Environment

- **Operating System:** Kali Linux
- **Environment:** Windows Subsystem for Linux (WSL2)
- **Shell:** Bash
- **Text Conversion Utility:** Enscript
- **PostScript to PDF Utility:** ps2pdf
- **PDF Information Utility:** pdfinfo
- **PDF Viewer:** Evince

## 3. Checking and Installing Enscript

I first checked whether `enscript` was installed:

```bash
which enscript
```

If it was not installed, I used:

```bash
sudo apt update
sudo apt install enscript -y
```

I verified the installation using:

```bash
enscript --version
```

## 4. Selecting the Input Text File

The exercise suggested using `/var/dmesg`.

I checked whether the file existed:

```bash
ls -l /var/dmesg
```

If the suggested file was unavailable, I used `/var/log/dpkg.log` as an alternative system log file.

I checked the alternative file:

```bash
ls -lh /var/log/dpkg.log
```

## 5. Converting the Text File to PostScript

I used `enscript` to convert the text file into PostScript format:

```bash
enscript -p /tmp/dmesg.ps /var/log/dpkg.log
```

### Explanation

- `enscript` converts plain text into PostScript.
- `-p` specifies the output file.
- `/tmp/dmesg.ps` is the destination PostScript file.
- `/var/log/dpkg.log` is the original text file.

I verified that the PostScript file was created:

```bash
ls -lh /tmp/dmesg.ps
```

## 6. Converting PostScript to PDF

I checked whether `ps2pdf` was available:

```bash
which ps2pdf
```

If unavailable, I installed Ghostscript:

```bash
sudo apt install ghostscript -y
```

I then converted the PostScript document into PDF format:

```bash
ps2pdf /tmp/dmesg.ps /tmp/dmesg.pdf
```

I verified the resulting PDF:

```bash
ls -lh /tmp/dmesg.pdf
```

## 7. Viewing and Comparing the Documents

I used Evince to open the PostScript and PDF documents:

```bash
evince /tmp/dmesg.ps
```

```bash
evince /tmp/dmesg.pdf
```

If Evince was not installed, I could install it using:

```bash
sudo apt install evince -y
```

### Comparison

The PDF document should retain the same text and general page layout as the original PostScript document.

Minor differences in rendering may occur depending on the document viewer.

## 8. Direct Conversion from Text to PDF

The exercise also required finding a way to create a PDF without saving an intermediate PostScript file.

I achieved this using a Linux pipe:

```bash
enscript -o - /var/log/dpkg.log | ps2pdf - /tmp/dmesg-direct.pdf
```

### Explanation

- `enscript -o -` sends PostScript output to standard output.
- `|` passes the output from one command to another.
- `ps2pdf -` reads PostScript from standard input.
- `/tmp/dmesg-direct.pdf` specifies the resulting PDF file.

This method avoids creating an intermediate PostScript file on disk.

I verified the resulting document:

```bash
ls -lh /tmp/dmesg-direct.pdf
```

## 9. Installing and Using pdfinfo

I checked whether `pdfinfo` was installed:

```bash
which pdfinfo
```

If unavailable, I installed the Poppler utilities package:

```bash
sudo apt install poppler-utils -y
```

I inspected the PDF metadata:

```bash
pdfinfo /tmp/dmesg.pdf
```

### Information Retrieved

The `pdfinfo` command displays several details about a PDF document, including:

| Metadata | Description |
|---|---|
| Title | Document title |
| Creator | Application that created the document |
| Producer | Software that generated the PDF |
| Pages | Total number of pages |
| Page size | Dimensions of the document pages |
| File size | Size of the PDF file |
| PDF version | PDF specification version |
| Creation date | Date the PDF was created |
| Modification date | Date the PDF was modified |

The actual values depend on the input file and conversion software.

## 10. Final File Verification

I used the following command to verify the generated documents:

```bash
ls -lh /tmp/dmesg.ps /tmp/dmesg.pdf /tmp/dmesg-direct.pdf
```

Expected files:

- `dmesg.ps` – PostScript document.
- `dmesg.pdf` – PDF converted from PostScript.
- `dmesg-direct.pdf` – PDF generated directly using a pipe.
