# Kali Linux Remote Access on Windows 10 Using WSL 2

## 1. Overview

This lab documents running Kali Linux on Windows 10 using Windows Subsystem for Linux 2 (WSL 2) and accessing its graphical desktop remotely.

**Main components:**

* **WSL 2:** Runs Kali Linux on Windows using lightweight virtualization and a Linux kernel.
* **XFCE:** A lightweight graphical desktop environment providing windows, menus, panels, and applications.
* **Remote desktop:** Allows access to Kali's graphical interface from another interface or client.
* **XRDP:** An optional service that enables Remote Desktop Protocol (RDP) connections to Linux.

## 2. Enable WSL 2 on Windows

Open PowerShell as Administrator.

Enable the required Windows features:

```powershell
dism.exe /online /enable-feature /featurename:Microsoft-Windows-Subsystem-Linux /all /norestart

dism.exe /online /enable-feature /featurename:VirtualMachinePlatform /all /norestart
```

Restart Windows when prompted.

Set WSL 2 as the default:

```powershell
wsl --set-default-version 2
```

Check installed distributions and their WSL versions:

```powershell
wsl --list --verbose
```

## 3. Launch and Manage Kali Linux

Launch Kali from PowerShell:

```powershell
wsl -d kali-linux
```

Check running distributions:

```powershell
wsl --list --running
```

Stop Kali:

```powershell
wsl --terminate kali-linux
```

Stop all running WSL distributions:

```powershell
wsl --shutdown
```

## 4. Install the XFCE Desktop

Inside Kali Linux, update the package list and upgrade installed packages:

```bash
sudo apt update && sudo apt upgrade -y
```

Install the XFCE desktop environment:

```bash
sudo apt install kali-desktop-xfce -y
```

XFCE provides the graphical interface needed for a desktop-based Kali session.

## 5. Remote Desktop Access

The current environment uses a browser-based remote desktop at:

**`http://localhost:6080`**

Open this address in a browser on the Windows computer when the remote desktop service is running.

Port `6080` is commonly used by browser-based VNC clients such as noVNC. The exact service and startup procedure depend on the remote desktop setup.

> Note: Browser-based desktop access and XRDP are different methods. Do not assume that XRDP is responsible for port `6080`.

## 6. Optional: Configure XRDP

XRDP allows compatible Remote Desktop clients to connect to a Linux graphical session using RDP, typically on TCP port `3389`.

Install XRDP inside Kali:

```bash
sudo apt install xrdp -y
```

Start the service:

```bash
sudo service xrdp start
```

Check its status:

```bash
sudo service xrdp status
```

XRDP requires a correctly configured desktop session, authentication, and network access. It is an alternative remote-access method and is not confirmed as part of the current browser-based setup.

## 7. Troubleshooting

### Kali does not start

Check the registered distributions:

```powershell
wsl --list --verbose
```

If Kali is running but needs to be restarted:

```powershell
wsl --terminate kali-linux
wsl -d kali-linux
```

### WSL cannot find the virtual disk

If WSL reports that `ext4.vhdx` cannot be found, the registered virtual disk path may be incorrect or the disk may be inaccessible.

Check the location of the disk and the WSL registration before moving, deleting, or repairing files.

### External drive reports filesystem errors

If Windows reports bad sectors or filesystem corruption on an external drive, avoid repeated repair attempts until important data is protected. Filesystem repair does not fix physical drive damage.

### Remote desktop does not open

Confirm that Kali and the relevant remote desktop service are running. Verify the correct address, port, and desktop configuration.

## 8. How the Components Work Together

| Component                    | Function                                    |
| ---------------------------- | ------------------------------------------- |
| WSL 2                        | Runs Kali Linux on Windows                  |
| XFCE                         | Provides the graphical desktop              |
| Browser-based remote desktop | Displays a desktop session in a web browser |
| XRDP                         | Provides RDP-based remote desktop access    |

## 9. Conclusion

This lab covers running Kali Linux on Windows 10 using WSL 2, installing a lightweight graphical desktop, and understanding remote desktop access.

The browser-based desktop at `http://localhost:6080` is the access method used in the current environment. XRDP is documented separately as an alternative.

**Security note:** Keep remote desktop services restricted to trusted networks or localhost unless remote exposure is specifically required and secured.
