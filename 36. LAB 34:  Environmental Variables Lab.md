

## 1. Lab Overview

This lab focuses on using environmental variables in Bash shell scripting.

The exercise involves writing a Bash script that prompts the user to enter a number, assigns a corresponding value to an environmental variable, exports the variable, and displays its value.

The script also demonstrates how to handle invalid user input using conditional statements and return codes.

## 2. Objectives

The objectives of this lab were to:

1. Prompt the user to enter either `1` or `2`.
2. Set an environmental variable named `EVAR` to `Yes` when the user enters `1`.
3. Set `EVAR` to `No` when the user enters `2`.
4. Assign `Unknown` when the user enters any other value.
5. Export the environmental variable.
6. Display the value of the environmental variable.
7. Use a return code to indicate invalid input.

## 3. Creating the Script

A Bash script named `testenv.sh` was created using the Nano text editor.

Command used:

```bash
nano testenv.sh
```

### Script Contents

```bash
#!/bin/bash

echo "Enter 1 or 2, to set the environmental variable EVAR to Yes or No"
read ans

# Set up a return code
RC=0

if [ $ans -eq 1 ]
then
    export EVAR="Yes"
else
    if [ $ans -eq 2 ]
    then
        export EVAR="No"
    else
# can only reach here with a bad answer
        export EVAR="Unknown"
        RC=1
    fi
fi
echo "The value of EVAR is: $EVAR"
exit $RC
```

## 4. Making the Script Executable

After creating and saving the script, executable permissions were granted using:

```bash
chmod +x testenv.sh
```

The script was executed using:

```bash
./testenv.sh
```

## 5. Understanding the Script

### A. Accepting User Input

```bash
read ans
```

The `read` command accepts input from the user and stores it in a variable named `ans`.

### B. Initializing the Return Code

```bash
RC=0
```

A variable named `RC` is initialized with a value of zero.

Zero indicates that the operation has not encountered an error.

### C. Checking the User's Input

```bash
if [ $ans -eq 1 ]
then
    export EVAR="Yes"
```

This condition checks whether the user entered `1`.

If true, the environmental variable `EVAR` is assigned the value `Yes`.

The second condition checks whether the user entered `2`:

```bash
if [ $ans -eq 2 ]
then
    export EVAR="No"
```

If the input is `2`, the variable is assigned the value `No`.

### D. Handling Invalid Input

```bash
export EVAR="Unknown"
RC=1
```

If the user enters a value other than `1` or `2`, the script assigns `Unknown` to the environmental variable.

The return code is changed to `1` to indicate that invalid input was received.

### E. Displaying the Environmental Variable

```bash
echo "The value of EVAR is: $EVAR"
```

The `echo` command displays the current value of the environmental variable.

### F. Exiting the Script

```bash
exit $RC
```

The script terminates using the return code stored in `RC`.

- `exit 0` indicates successful execution.
- `exit 1` indicates invalid input.
