

## 1. Objective
To gain practical experience with the Vim text editor using its built-in interactive tutorial.

## 2. Tools Used
- Kali Linux
- Vim text editor
- Linux terminal
- `vimtutor` utility

## 3. Procedure

### Step 1: Launch vimtutor

Executed the following command:

```bash
vimtutor
```

This launched Vim's built-in interactive tutorial.



<img width="1920" height="1200" alt="image" src="https://github.com/user-attachments/assets/dc1d0c65-8ca9-49f7-a460-1096aea857a2" />


### Step 2: Complete the Exercises

Worked through the initial tutorial lessons, practising cursor movement, text insertion, deletion and basic editing operations.

Commands practised included:

| Key / Command | Function |
|---|---|
| `h` | Move left |
| `j` | Move down |
| `k` | Move up |
| `l` | Move right |
| `i` | Enter Insert mode |
| `Esc` | Return to Normal mode |
| `x` | Delete a character |
| `dd` | Delete a line |
| `u` | Undo a change |
| `:w` | Save changes |
| `:q` | Exit Vim |

<img width="1920" height="1200" alt="image" src="https://github.com/user-attachments/assets/de7b08f4-19e2-4d8c-ba4c-8624443aaf3e" />


### Step 3: Exit the Tutorial

Pressed `Esc`, entered the following command and pressed Enter:

```vim
:q!

```

This exited Vim without saving changes.
