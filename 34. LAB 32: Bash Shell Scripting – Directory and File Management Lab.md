

## 1. Lab Overview

This lab demonstrates how to write and execute a Bash shell script that automates directory creation, file management, content writing, file reading, and cleanup operations using basic Linux commands.

The exercise focuses on combining multiple Linux commands into a single script that executes sequentially without requiring the user to enter each command manually.

## 2. Objectives

The objectives of this lab were to write a Bash script that:

1. Prompts the user to enter a directory name and creates it using `mkdir`.
2. Changes into the newly created directory and displays its location using `pwd`.
3. Creates several empty files using `touch` and verifies their existence and sizes using `ls`.
4. Adds content to the files using `echo` and output redirection.
5. Displays the contents of the files using `cat`.
6. Displays a goodbye message and removes the temporary directory and its contents.

## 3. Script Creation

Created a Bash script named:

`directory_lab.sh`

Command used:

```bash
nano directory_lab.sh
```

### Script Contents

```bash
#!/bin/bash

# Ask the user for a directory name
echo "Enter a directory name:"
read dirname

# Create the directory
mkdir "$dirname"

# Change into the new directory
cd "$dirname" || exit

# Display the current directory
echo "You are now in:"
pwd

# Create several empty files
touch file1.txt file2.txt file3.txt

# List the files to verify they are empty
echo "Displaying the newly created files:"
ls -l file1.txt file2.txt file3.txt

# Add content to the files
echo "This is the first file." > file1.txt
echo "This is the second file." > file2.txt
echo "This is the third file." > file3.txt

# Display file contents
echo "Displaying file contents:"
cat file1.txt file2.txt file3.txt

# Say goodbye
echo "Goodbye! Cleaning up..."

# Return to the parent directory
cd ..

# Remove the directory and its contents
rm -r "$dirname"

echo "Cleanup completed successfully!"
```

## 4. Making the Script Executable

After writing the script, it was saved and made executable using:

```bash
chmod +x directory_lab.sh
```

The script was then executed using:

```bash
./directory_lab.sh
```

Input:


This confirmed that the directory was successfully created and the script had entered it.

### Step 2: Creating and Verifying Empty Files

- file1.txt
- file2.txt
- file3.txt

It then used `ls -l` to verify the files.

Output:


```bash

echo "This is the third file." > file3.txt
```

The `>` operator redirected the output into the respective files.

### Step 4: Displaying File Contents

The script used the `cat` command to display the contents of all three files.

Output:


This confirmed that the content had been successfully written to the files and could be retrieved.

After displaying the file contents, the script printed a goodbye message, returned to the parent directory, and removed the temporary directory.


## 6. Commands and Concepts Learned

| Command / Concept | Description |
|---|---|
| `#!/bin/bash` | Specifies Bash as the script interpreter. |
| `echo` | Displays text in the terminal. |
| `read` | Accepts input from the user. |
| `mkdir` | Creates a directory. |
| `cd` | Changes the current working directory. |
| `pwd` | Displays the current working directory. |
| `touch` | Creates empty files when they do not exist. |
| `ls -l` | Displays detailed file information, including file sizes. |

| `cat` | Displays file contents. |

| `read` and variables | Allow scripts to accept and use user-provided information. |

## 7. Challenges Encountered

### Challenge 1: Running mkdir Without an Argument

Initially, the following command was entered directly into the terminal:

```bash
mkdir
```

The terminal returned:

```text
mkdir: missing operand
Try 'mkdir --help' for more information.
```

**Explanation:**

The `mkdir` command requires a directory name as an argument.

**Correct usage:**

```bash
mkdir my_lab
```

In the script, this was handled dynamically using:

```bash
mkdir "$dirname"
```

### Challenge 2: Accessing the Script Using cat

An attempt was made to display the script using:

```bash
cat lab_sh
```

This returned a file-not-found error because the filename was incorrect.

The correct command is:

```bash
cat directory_lab.sh
```

### Challenge 3: Attempting to Access the Deleted Directory

After successful execution, the following command was attempted:

```bash
cat my_lab
```

The terminal returned:

```text
cat: my_lab: No such file or directory
```

**Explanation:**

This was expected because the script included a cleanup operation:

```bash
rm -r "$dirname"
```

The directory and its contents had already been deleted.

This demonstrated how scripts can perform automatic cleanup after completing their tasks.
