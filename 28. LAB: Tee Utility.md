Task
The tee utility is very useful for saving a copy of your output while you are watching it being generated.

Execute a command such as doing a directory listing of the /etc directory:

student:/tmp> ls -l /etc

while both saving the output in a file and displaying it at your terminal.
Solution
ls -l /etc | tee /tmp/etc-listing.txt
Explanation
1. ls -l /etc – Lists the contents of the /etc directory in long format.
2. | – Sends the output of the first command to the next command.
3. tee – Displays the output on the terminal and saves a copy to a file.
4. /tmp/etc-listing.txt – Specifies the file where the output is saved.
Verify the saved output
cat /tmp/etc-listing.txt
Expected Result
- The directory listing is displayed in the terminal.
- A copy of the same output is saved in /tmp/etc-listing.txt.
Key Point: The tee command allows you to display command output and save it to a file simultaneously.
