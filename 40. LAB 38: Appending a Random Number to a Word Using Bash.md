

## 1. Objective

The objective of this exercise was to write a Bash script that:

1. Takes a word as a command-line argument.
2. Generates a random number.
3. Appends the random number to the supplied word.
4. Displays the combined result.

## 2. Tools and Environment

- **Operating System:** Kali Linux
- **Environment:** Windows Subsystem for Linux (WSL2)
- **Shell:** Bash
- **Text Editor:** Nano

## 3. Creating the Script

I created a Bash script named `random.sh` using Nano:

```bash
nano random.sh
```

### Script: random.sh

```bash
#!/bin/bash

# Get the word from the command-line argument
word=$1

# Generate a random number
random_number=$RANDOM

# Append the random number to the word
result="${word}${random_number}"

# Display the result
echo "Result: $result"
```

## 4. Making the Script Executable

After saving the script, I assigned it executable permissions:

```bash
chmod +x random.sh
```

## 5. Executing the Script

I executed the script by supplying different words as command-line arguments.

```bash
./random.sh Charles
./random.sh Linux
./random.sh Kali
./random.sh Cybersecurity
```

### Execution Results

```text
charles@DESKTOP-LCFMHCU:~$ ./random.sh Charles
Result:Charles22628

charles@DESKTOP-LCFMHCU:~$ ./random.sh Linux
Result:Linux31399

charles@DESKTOP-LCFMHCU:~$ ./random.sh Kali
Result:Kali14115

charles@DESKTOP-LCFMHCU:~$ ./random.sh Cybersecurity
Result:Cybersecurity12316
```

**Observation:** Each execution generated a different random number and appended it to the supplied word.

*Note: Random numbers will vary between executions.*

## 6. Challenges Encountered and Solutions

### Challenge 1: Unexpected EOF While Looking for Matching Quotation Mark

During the initial execution, I encountered the following error:

```text
./random.sh: line 15: unexpected EOF while looking for matching `"'
```

**Cause:**

The error indicated that the script contained an opening double quotation mark without a corresponding closing quotation mark. This resulted in a Bash syntax error.

**Solution:**

I reopened the script using Nano:

```bash
nano random.sh
```

I reviewed the script, corrected the quotation marks and ensured that the commands were properly written.

I then saved the changes and executed the script again.

### Challenge 2: Understanding Command-Line Arguments

The script needed to accept a word when executed rather than request input interactively.

**Solution:**

I used `$1` to retrieve the first command-line argument:

```bash
word=$1
```

This allowed me to supply different words directly when running the script.

## 7. Understanding the Commands and Variables

| Command/Variable | Description |
|---|---|
| `#!/bin/bash` | Specifies Bash as the script interpreter. |
| `$1` | Retrieves the first command-line argument. |
| `$RANDOM` | Generates a pseudo-random integer between 0 and 32767. |
| `word=$1` | Stores the supplied word in a variable. |
| `random_number=$RANDOM` | Stores the generated random number. |
| `${word}${random_number}` | Combines the word and random number. |
| `echo` | Displays the resulting string. |
| `chmod +x` | Gives the script executable permission. |
