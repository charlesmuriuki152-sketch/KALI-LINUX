

## 1. Objective

To write a Bash shell script that accepts two strings as command-line arguments and performs the following operations:

1. Checks whether the first string has zero length.
2. Checks whether the second string has non-zero length.
3. Calculates the length of both strings.
4. Determines which string is longer or whether both have equal lengths.
5. Compares the two strings to determine whether they are identical.

## 2. Creating the Script

Created a script named `strings.sh` using the Nano text editor.

```bash
nano strings.sh
```

## 3. Script Implementation

```bash
#!/bin/bash

# Check whether two arguments were provided
if [ "$#" -ne 2 ]; then
    echo "Usage: $0 string1 string2"
    exit 1
fi

# Read the two strings
str1="$1"
str2="$2"

# 1. Test string lengths
if [ -z "$str1" ]; then
    echo "The first string has zero length."
else
    echo "The first string has non-zero length."
fi

if [ -n "$str2" ]; then
    echo "The second string has non-zero length."
else
    echo "The second string has zero length."
fi

# 2. Determine string lengths
len1=${#str1}
len2=${#str2}

echo "Length of first string: $len1"
echo "Length of second string: $len2"

if [ "$len1" -gt "$len2" ]; then
    echo "The first string is longer."
elif [ "$len2" -gt "$len1" ]; then
    echo "The second string is longer."
else
    echo "Both strings have equal length."
fi

# 3. Compare the strings
if [ "$str1" = "$str2" ]; then
    echo "Both strings are the same."
else
    echo "The strings are different."
fi
```

## 4. Making the Script Executable

## 6. Bash Operators and Concepts Learned

| Operator / Parameter | Description |
|---|---|
| `$1` | Represents the first command-line argument. |
| `$2` | Represents the second command-line argument. |
| `$#` | Returns the number of arguments supplied. |
| `-z` | Tests whether a string has zero length. |
| `-n` | Tests whether a string has non-zero length. |
| `${#str1}` | Returns the length of the first string. |
| `-gt` | Tests whether one integer is greater than another. |
| `-lt` | Tests whether one integer is less than another. |
| `=` | Compares two strings for equality. |
| `if` | Executes commands based on a condition. |
| `elif` | Checks another condition when the previous condition is false. |
| `else` | Executes when preceding conditions are false. |
| `exit 1` | Terminates the script with an error status. |
