Using **wc** (word count), find out how many lines, words, and characters there are in all the files in **/var/log** that have the **.log** extension.

##### Solution

```bash
wc -l -w -m /var/log/*.log
```

##### Explanation

1. `wc` – Counts lines, words, and characters.
2. `-l` – Counts the number of lines.
3. `-w` – Counts the number of words.
4. `-m` – Counts the number of characters.
5. `/var/log/*.log` – Selects all files in `/var/log` that have the `.log` extension.

##### Expected Result

The command displays the line count, word count, and character count for each matching `.log` file, followed by a total for all matching files.

**Key Point:** The `wc` command can count lines, words, and characters in multiple files at once.
