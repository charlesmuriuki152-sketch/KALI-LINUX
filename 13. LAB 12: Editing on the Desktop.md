

## 1. Objective
To practise editing an existing Linux text file using GNOME Text Editor and verifying saved changes through the terminal.

## 2. Tools Used
- Kali Linux
- GNOME Text Editor
- Linux terminal
- `cat` command

## 3. Procedure

### Step 1: Open GNOME Text Editor

Launched GNOME Text Editor from the applications menu.

Alternatively, the following terminal command can be used:

```bash
gnome-text-editor
```

Opened the file created in Lab 9.1:


Alternatively:

```bash
gnome-text-editor /tmp/mynotes.txt
```


### Step 4: Save Changes

Pressed `Ctrl + S` to save the modifications.

### Step 5: Verify Changes Using Cat

Returned to the terminal and executed:

```bash
cat /tmp/mynotes.txt
```

The command displayed the updated file contents, confirming that the changes were saved.

## 4. Commands and Shortcuts Learned

| Command / Shortcut | Purpose |
|---|---|
| `gnome-text-editor` | Launches GNOME Text Editor. |
| `gnome-text-editor /tmp/mynotes.txt` | Opens a specific file. |
| `Ctrl + S` | Saves changes. |
| `cat /tmp/mynotes.txt` | Displays the updated file contents. |
