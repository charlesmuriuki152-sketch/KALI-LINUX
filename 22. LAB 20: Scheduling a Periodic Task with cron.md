

## Objective

To learn how to schedule recurring tasks in Linux using the `cron` scheduling service. The practical exercise creates a task that runs every day at 10:00 a.m.

## 1. Installing cron

First, update the package lists:

```bash
sudo apt update
```

Install cron:

```bash
sudo apt install cron -y
```

**Explanation:**

The `cron` package provides the scheduling service used to execute recurring tasks automatically.

## 2. Starting the cron Service

Start the service:

```bash
sudo service cron start
```

Check its status:

```bash
sudo service cron status
```

**Observation:**

The cron service was initially unavailable because it was not installed. After installing the package, the service could be started.

## 3. Opening the User Crontab

Command:

```bash
crontab -e
```

**Explanation:**

- `crontab` manages scheduled tasks for a user.
- `-e` opens the user's crontab file for editing.

## 4. Creating the Daily Scheduled Task

Add the following line to the crontab:

```bash
0 10 * * * /usr/bin/date >> /home/charles/cron-result.txt
```

**Explanation:**

This schedules the `date` command to execute every day at 10:00 a.m. and append its output to `/home/charles/cron-result.txt`.

## 5. Understanding Cron Scheduling Fields

Cron uses five scheduling fields:

| Field | Value | Meaning |
|---|---|---|
| Minute | `0` | At minute zero |
| Hour | `10` | At 10 a.m. |
| Day of month | `*` | Every day of the month |
| Month | `*` | Every month |
| Day of week | `*` | Every day of the week |

The asterisk (`*`) means any or every applicable value.

## 6. Saving and Verifying the Cron Job

After adding the command, save the crontab.

Verify the scheduled task:

```bash
crontab -l
```

Expected output:

```text
0 10 * * * /usr/bin/date >> /home/charles/cron-result.txt
```

This confirms that the scheduled task has been saved.

## 7. Understanding Output Redirection

The scheduled command contains:

```bash
/usr/bin/date >> /home/charles/cron-result.txt
```

- `/usr/bin/date` executes the date command.
- `>>` appends output to an existing file or creates the file if it does not exist.
- `/home/charles/cron-result.txt` stores the results.

Unlike `>`, which overwrites existing file contents, `>>` preserves previous results and adds new output.

To inspect the recorded results:

```bash
cat /home/charles/cron-result.txt
```

## 8. Important Cron Commands

| Command | Function |
|---|---|
| `sudo apt install cron -y` | Installs cron |
| `sudo service cron start` | Starts the cron service |
| `sudo service cron status` | Checks cron service status |
| `crontab -e` | Edits the user's scheduled tasks |
| `crontab -l` | Lists scheduled tasks |
| `crontab -r` | Removes the user's crontab |

## 9. Key Learnings

- `cron` is used to schedule recurring tasks in Linux.
- `crontab` manages scheduled jobs for individual users.
- Cron uses five scheduling fields: minute, hour, day of month, month and day of week.
- The asterisk (`*`) represents every applicable value.
- `>>` appends command output to a file.
- Cron jobs execute automatically when their scheduled time arrives
