

## Objective

Learn how to use the Linux `man` command to read manual pages, search for topics, and find manual pages in specific sections.

---

## 1. Reading a man Page

### Task

Bring up the man page for `man` itself, then scroll down to its `EXAMPLES` section.

### Command

```bash
man man
```

### Explanation

* `man` stands for manual.
* The second `man` specifies the command whose manual page you want to read.
* This command opens the manual page for the `man` command itself.

### Steps

1. Open the terminal.
2. Type `man man` and press Enter.
3. Scroll down using the Down Arrow key or the Spacebar.
4. To search for the `EXAMPLES` section, type `/EXAMPLES` and press Enter.
5. Press `n` to find the next match if necessary.
6. Press `q` to exit the manual page.

### Result

The manual page for `man` opens, allowing you to read its documentation and examples.

---

## 2. Finding man Pages by Topic

### Task

Suppose you do not know the exact command name. Find the manual pages available that document file compression.

### Command

```bash
man -k compression
```

### Explanation

* `man` searches or displays manual information.
* `-k` searches manual page names and descriptions using a keyword.
* `compression` is the topic being searched.

This command lists manual pages whose names or descriptions match the keyword.

### Examples of Related Commands

* `gzip` — Compresses files.
* `bzip2` — Compresses files.
* `xz` — Compresses files.

The results depend on the software and manual pages installed on your Linux system.

### Alternative Command

```bash
apropos compression
```

The `apropos` command performs the same type of search as `man -k`.

### Result

A list of manual pages related to file compression is displayed.

**Note:** If no results appear, try:

```bash
man -k compress
```

The search results depend on the keywords used in the manual page descriptions.

## 3. Finding a man Page in a Specific Section

### Task

Bring up the man page for the `printf` library function. Identify which manual section contains library functions.

### Command

```bash
man 3 printf
```

### Explanation

* `man` opens a manual page.
* `3` specifies manual section 3.
* `printf` is the name of the library function.

This command requests the manual page for the C library `printf()` function.

### Common Linux Manual Sections

| Section | Description                          |
| ------- | ------------------------------------ |
| 1       | User commands                        |
| 2       | System calls                         |
| 3       | Library functions                    |
| 4       | Special files and devices            |
| 5       | File formats and configuration files |
| 6       | Games                                |
| 7       | Miscellaneous topics                 |
| 8       | System administration commands       |

### Answer

**Library functions are documented in Section 3.**

Using `man 3 printf` specifically requests the library function documentation rather than a command with the same name.

### Result

The manual page for the C library `printf()` function opens, provided that the relevant manual page is installed.

---

## Conclusion

In this lab, we learned how to use the Linux `man` command to access documentation.

* `man man` opens the manual page for the `man` command.
* `man -k compression` searches for manual pages related to compression.
* `man 3 printf` opens the manual page for the C library `printf()` function.
* Manual Section 3 contains library functions.
* Pressing `q` exits a manual page.

These commands help Linux users find information about commands, programs, and library functions directly from the terminal.
