

1. OBJECTIVE

Extract a unique list of login shells from the /etc/passwd file using awk, sort, and uniq.

2. UNDERSTANDING THE /etc/passwd FILE

The /etc/passwd file stores information about user accounts on a Linux system.

Each line contains seven fields separated by colons (:).

Example:
charles:x:1000:1000::/home/charles:/bin/bash

The seven fields are:

1. Username
2. Password placeholder
3. User ID (UID)
4. Group ID (GID)
5. User information (GECOS)
6. Home directory
7. Login shell

The login shell is stored in field 7.

3. EXTRACTING THE SEVENTH FIELD USING AWK

Command:

awk -F: '{print $7}' /etc/passwd

Explanation:

- awk processes and extracts information from text.
- -F: sets the colon as the field separator.
- $7 selects the seventh field.
- print displays the selected field.
- /etc/passwd specifies the file being processed.

The command displays login shells, including repeated entries.

4. SORTING AND REMOVING DUPLICATES USING SORT -U

Command:

awk -F: '{print $7}' /etc/passwd | sort -u

Explanation:

- The pipe (|) sends output from one command to another.
- sort arranges the shell paths alphabetically.
- -u removes duplicate entries.

ACTUAL KALI LINUX OUTPUT:

/bin/bash
/bin/false
/bin/sh
/bin/sync
/sbin/nologin
/usr/sbin/nologin

The command successfully produced six unique login shells.

5. ALTERNATIVE METHOD USING SORT AND UNIQ

Command:

awk -F: '{print $7}' /etc/passwd | sort | uniq

Explanation:

1. awk extracts the seventh field.
2. sort arranges the entries alphabetically.
3. uniq removes consecutive duplicate entries.

The expected output is the same six unique login shells.

6. DIFFERENCE BETWEEN SORT -U AND SORT | UNIQ

sort:
Arranges lines alphabetically.

uniq:
Removes consecutive duplicate lines.

sort -u:
Sorts and removes duplicates.

sort | uniq:
Sorts first, then removes duplicates.

IMPORTANT:
Running uniq without sorting first may leave duplicates if identical entries are separated by other lines.

7. UNDERSTANDING THE SIX LOGIN SHELLS

/bin/bash
Bash command-line shell.

/bin/false
Prevents successful login.

/bin/sh
Standard Unix shell.

/bin/sync
Runs the sync command instead of providing an interactive shell.

/sbin/nologin
Prevents interactive login.

/usr/sbin/nologin
Also prevents interactive login.
